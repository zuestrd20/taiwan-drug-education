# 台灣30年毒品趨勢與教育報告

繁體中文學生與教師教材，範圍1996–2025，2026資料另列。

## 原則
官方來源優先。人口調查、查獲、定罪、醫療通報、監所存量與新入監流量分開；再犯群組與追蹤期間明示。缺值不補零。國際資料不同年齡與定義不做排名。

## 使用
純靜態HTML/CSS/JS，無追蹤器、無登入、測驗不儲存。GitHub Pages從main根目錄發布。下載資料在data/，來源索引在網頁末尾。

## 驗證
以瀏覽器檢查桌面、窄版、搜尋與篩選、年範圍、測驗重設、列印與來源跳轉。資料與醫療／法律內容另做來源稽核。

## 內容範圍
一般教育資訊，不取代醫療或法律諮詢；不提供製造、取得、使用、劑量或規避執法指引。
